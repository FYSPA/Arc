  <h1>Arc</h1>
  <p>
    <strong>Arc App es un reproductor de música local compatible con los formatos FLAC, WAV y MP3. Está construido íntegramente con tecnología propia: Arc Engine (motor de audio personalizado) y Arx Canvas (biblioteca de renderizado de interfaz de usuario personalizada). Se desarrolló como un proyecto personal de aprendizaje.</strong>
